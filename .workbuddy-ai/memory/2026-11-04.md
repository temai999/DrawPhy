# 2026-11-04

## Ribbon 菜单重构（Office Ribbon 规范）

将 DrawPhy 的顶部菜单从 6 标签页重构为 5 标签页，遵循 Office Ribbon 分组规范：

**旧结构（问题）：**
- 文件 / 编辑 / 绘图 / 部件 / 排列 / 视图（6 个标签页）
- "适应画布"在编辑、排列、视图三个标签页重复出现
- 编辑标签页过空（仅撤销/重做 + 适应画布）
- 排列标签页过空（仅组合/取消组合 + 适应画布）
- 绘图标签页的文字/编辑/变换工具藏在通用"折叠组"按钮后面，不符合 Ribbon 直观展示原则

**新结构：**
- **文件** → 文件操作 / 导出 / 示例（3 组）
- **开始**（合并旧编辑+排列）→ 撤销 / 组合 / 层级 / 变换 / 对齐（5 组）
- **绘图** → 基本图形 / 文字与标注 / 编辑工具 / 样式（4 组，原折叠组展开为内联组）
- **部件** → 学科分类 / 通用组件（2 组，移除无用的"提示"组）
- **视图** → 显示 / 缩放（2 组，新增放大/缩小按钮）

**改动文件：**
- `index.html` — 标签页和 ribbon 分组结构
- `src/ui.js` — buildTools() 填充 toolTextList/toolEditList；bindTopbar() 绑定 home 标签页 data-act 按钮和缩放按钮；移除 btnFit2/btnFit3 和 gfold 绑定
- `assets/editor.css` — .rcells max-width 200px → 320px（适配展开后的工具组宽度）
