## 模块迁移阶段 2 完成：arc / path / text

### 新增模块（3 个，基础类型迁移全部完成，9/9）

- `src/modules/primitives/arc.js` — 圆弧（cx,cy,r,a0,a1）
  - bbox: 24 点采样求包围盒
  - hitTest: |d-r|≤tol 且角度在 a0..a1 范围内（含 360° 回绕）
  - mirror: 角度镜像 — axis='v' → a0'=-A1,a1'=-A0；axis='h' → a0'=180-A1,a1'=180-A0
  - nodes: center + radius point（新增编辑手柄，原 switch 无）
  - scale: r *= k（k = (|sx|+|sy|)/2）

- `src/modules/primitives/path.js` — SVG 路径（d 字符串）
  - bbox/hitTest/anchors 委托 G.pathBBox / G.pathDistance / G.parsePath
  - translate/scale/mirror 委托 G.mapPath
  - nodes: 空（path 控制点编辑待后续阶段）
  - paint 不带 extra 参数（与 R.primitive 原始行为一致）

- `src/modules/primitives/text.js` — 文字（x,y,text,size,anchor,rot,weight）
  - bbox: 字号估算 len = text.length × size × 0.62 + 4
  - hitTest: bbox ± 4px
  - render: 返回 {tag:'text', children:[tspan...]} drawable 树
  - 上下标: 用 DP.render.parseText() 解析 x^{2}/A_{1}，生成 tspan dy 序列
  - **关键修正**: DP.render 懒查找 — render.js 加载顺序晚于 text.js，
    var R = DP.render 在工厂执行时为 undefined，必须延迟到 render 方法内获取
