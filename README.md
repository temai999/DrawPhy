# DrawPhy · 科学绘图板

对标 EE 的「绘图 + 部件」能力的**本地网页编辑器**：纯静态、零依赖，双击即用，画完直接导出 PNG / SVG。

> 调研报告：`docs/EE绘图与部件能力复刻调研报告.html`（能力拆解、选型理由、能力边界与二期路线）

---

## 1. 打开方式

直接双击 `index.html`，或：

```powershell
Start-Process "D:\Trae CN\myPro\DrawPhy\index.html"
```

- 不需要 Node、npm、构建、联网。
- 想看效果：地址后加 `?sample=1`，或在顶栏点「示例」插入一张示例图（串联电路 + 受力分析 + 凸透镜）。
- 上次的画会自动留在 localStorage，重新打开会提示恢复。

## 4. 拖动体系（EE 手感的核心）

| 操作 | 效果 |
| --- | --- |
| 部件库**按住拖入**画布 | 拖到画布出现半透明预览块（缩略图 + 名称），进入画布变蓝边高亮；松手即落件并切回选择工具。只单击不拖则退化为「选中该部件工具，连续放置」 |
| 选中后拖动 | 移动对象，旁边浮标实时显示 `dx , dy`；贴网格、贴其它对象的边/中线时出现洋红参考线 |
| `Alt`/`Ctrl` + 拖 | 拖动复制：原对象留在原地，拖走的是副本 |
| `Shift` + 拖 | 锁轴向：水平或竖直单向移动 |
| 选中单条线/箭头 | 两端出现圆形手柄，可直接拖端点改长度/方向；已粘附的端点显示为**橙色** |
| 端点吸附到对象后松手 | 自动**粘附**（记录相对宿主的偏移）；此后拖动/缩放宿主，这条线跟着走，宿主被删则自动解绑 |
| 选中单个部件 | 包围盒上方出现旋转手柄，拖动改角度，`Shift` 吸附 15° |
| `空格` + 拖 | 平移画布（不动物体） |

粘附实现：`o.bind = { x1:{id,dx,dy}, x2:{id,dx,dy} }`，`dx/dy` 是端点相对宿主包围盒中心的偏移；每次重绘前 `M.applyBindings()` 重算端点，因此缩放宿主时线端也会跟着缩放。跨图层不留隐患。

## 5. 快速上手

1. **画线**：按 `L`，按下拖动。靠近已有线段的端点/中点会自动吸附，方向接近水平会自动锁正交。
2. **画电路**：左侧「部件库 → 电学」，把电池**直接拖到画布**（拖入时有预览，落点会吸附）；再用「线」工具把端子连起来——线端点吸附到部件端子松手后会自动粘附，之后移动电池，导线跟着走。
3. **改样式**：选中对象 → 右侧属性面板改线色、线宽、虚线、填充、字号。
4. **改颜色不重画**：部件内部所有线条继承实例线色，选中电池改一次颜色，整块符号就变。
5. **写公式**：按 `T` 落字，输入 `v_{0}` 得到 v₀，`x^{2}` 得到 x²。
6. **导出**：顶栏「导出 PNG」为 2× 倍率；「导出 SVG」为矢量，可放大印刷。

## 7. 加一个新部件

在 `src/parts.js` 里追加一条定义即可，无需改渲染代码：

```js
list.push({
  id: 'newPart', name: '新部件', cat: '力学', w: 80, h: 40,
  shapes: [
    L(0, 20, 20, 20),        // 线
    R(20, 8, 40, 24, 3),     // 矩形（末位为圆角）
    C(60, 20, 8),            // 圆
    T(40, 12, 'A', 12),      // 文字
    SF(P([[70,12],[80,20],[70,28]], true)), // 实心多边形（跟随线色）
  ],
});
```

约定：坐标原点在**左上角**，所有图元落在 `0..w / 0..h` 内，线宽/线色由实例样式继承。

## 8. 已知限制（与报告第 8 节一致）

- 修剪只支持**直线**；折线/圆/矩形被打断后暂不支持点段删除。
- 普通图形（矩形/椭圆等）仍不支持任意角度旋转，只能 90° 步进；**部件**可自由旋转，**文字**支持 90° 步进旋转。
- 填充是「整对象上色」，不是种子填充；**布尔并/差/交**未实现。
- 部件是静态符号，暂无「参数联动」（如滑片位置、变阻值）。
- 无图层面板、无多页、无 PDF 导出。
- 贝塞尔目前是二次曲线，暂无三次曲线与控制柄编辑；徒手线只抽稀，不做贝塞尔拟合。
- `file://` 下复制图片到剪贴板可能被浏览器拒绝，会自动回退为下载 PNG。
